# Carnival demo

Playable web build of Carnival, a cooperative lantern-festival date for two. Open the site on a phone: solo practice (with a "Play as" switch to try the other seat) and two-players-on-one-keyboard run entirely in the browser. Two-phone private rooms need the full app's server and are not part of this static build.

Add `?quality=low` to the URL on a slow phone, or `?quality=high` to pin full quality.
